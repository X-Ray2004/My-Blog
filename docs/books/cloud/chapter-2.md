# Chapter 2

Module 2 : **AWS Pricing Strategies*** Pay what you use.

* Pay less when you reserve.
* Pay less when you use more as AWS grows.
* **Free Services:** IAM and Auto Scaling.

**Financial Analysis**

* **TCO (Total Cost of Ownership):** Includes server costs, storage, network, and IT labor costs (covers both hardware & software benefits).
* **TCO Analysis:** Compares on-premises costs vs. cloud costs.
* **ROI (Return on Investment):** Measures the financial return gained vs. the investment made.

**AWS Organizations & Billing**

* **AWS Organizations:** Manages multiple accounts centrally using IAM + Policies + Service Control Policies (SCPs).
* **Workflow:** Create Organization → Create Organizational Units (OUs) → Create SCPs → Test restrictions.
* **Billing Dashboard:** Tracks month-to-date costs.
* **Billing Access Tools:** Budgets, Usage Reports, Cost Explorer.

**Technical Support Models**

* **Support Plans (By Use Case):** Experimenting, Production, Business, Business-critical.
* **Support Plans (By Tier):** Basic, Developer, Business, Enterprise.
* **Enterprise Add-ons:****TAM:** Technical Account Manager.**Trusted Advisor:** Automated best-practice checks.**Concierge:** Specialized customer support.
