# AWS Foundation (AWS ACADEMY)

<!-- more -->


Module 1 : **Cloud Computing Basics*** **Definition:** On-demand delivery of IT resources over the internet (Pay-as-you-go).

* **Mindset:** Stop thinking in hardware; solves infrastructure problems; highly flexible.
* **Efficiency:** Eliminates undifferentiated heavy lifting tasks.

**Cloud Service Models**

* **IaaS, PaaS, SaaS.**
* *Rule:* More IT resources managed by AWS → Less control you have.

**6 Advantages of Cloud Computing**

* Massive economies of scale.
* Stop guessing capacity.
* Increase speed and agility.
* Stop spending on running data centers.
* Go global in minutes.

**AWS Basics**

* **Web Services:** Applications exchanging data over the web.
* **AWS Web Server:** A server hosted on AWS to serve apps/websites.
* **3 Ways to Interact with AWS:**AWS Management Console (GUI)AWS CLI (Command Line)SDKs (Code libraries)

**AWS CAF (Cloud Adoption Framework)**

* A structured framework to accelerate cloud adoption.
* **Core Capabilities:** People, Governance, Platform, Security, Operations.
* Organized through 6 different Perspectives.

**AWS Pricing Model**

* **Core Drivers:** Compute, Storage, Data Transfer.
